# Keysor

An agentic iOS keyboard — type an intent, hold the Keysor bar, get the result in place.

Built with **Expo (SDK 57)**. Visual language matches Acti-style light glassmorphism: frosted keyboard, skill cards, floating tab bar.

## Run on iPhone

```bash
npm install
npx expo start
```

Scan with Camera / Expo Go.

## Tabs

1. **Keyboard** — glass QWERTY + Keysor bar (long-press to run)
2. **Skills** — assign / browse skill keys
3. **Builder** — describe a skill in chat
4. **Access** — claim lifetime early access

Bindings persist on device via AsyncStorage.
